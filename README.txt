# WIGLO Master Web Key (Anti-AI, Dark UI)

A practical “rulebook” for building **professional, modern dark websites** without the usual AI/template look.

It’s not a theme. It’s a **process + design system + QA checklist** that forces:
- neutral grey UI (no neon/glow)
- clean layout decisions (spacing > boxes)
- real interaction patterns (hover/active/focus)
- state-driven UI (no highlight desync bugs)
- “critic mode” polish before shipping

## What’s inside
- **Product thinking**: stop feature-soup, keep pages focused
- **Visual system**: neutral grey tokens, typography rules, anti-template patterns
- **Component recipes**: nav, tabs, buttons, inputs, lists, panels
- **Engineering standards**: state architecture, cross-page persistence, file structure
- **QA passes**: dead-UI smoke test, no-missing-wiring checklist, overlay click-eater prevention
- **Optional server rules**: only when a server is actually needed

## How to use it
1) **Attach or paste the key** into your prompt (or include it as a file).
2) Tell the AI:  
   - “Follow `WIGLO_Master_Web_Key` strictly. Run critic pass + QA before output.”
3) Ask for your website/app normally (even if your request is messy).
4) Expect a clean result in one go — and when something looks off, update the key with a new rule.
